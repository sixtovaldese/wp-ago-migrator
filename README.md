# aGo Migrator

Simple WordPress migrator: export site as a single archive (DB + uploads), import on the destination. **Free, no Pro tier.**

[English](#english) · [Español](#espanol)

---

## English

aGo Migrator packages WordPress content into a single archive to move a site between environments. Lightweight alternative to enterprise migration suites.

### Features

- Export to single archive (database, uploads).
- Import archive on the destination site.
- Search-replace of URLs on import.
- No external services.
